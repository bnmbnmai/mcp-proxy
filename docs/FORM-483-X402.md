# FDA Form 483 observation bodies — x402 door

Official posted/proactive Form 483 PDFs from the OII FOIA Electronic Reading Room. Observation text is copied from those PDFs. Does not invent observations. Does not scrape Redica. Does not wrap the free CMS 2567 CSV. Not warning letters. Not WASDE.

Listed on well-known / OpenAPI / llms.txt / shop catalog **only** when at least one real 483 body is cached. Unpaid `GET /form-483` is HTTP 402 either way.

## Source of truth

- https://www.fda.gov/about-fda/office-inspections-and-investigations/oii-foia-electronic-reading-room
- Official DataTables JSON for that same room: https://www.fda.gov/datatables-json/ora-foia-reading.json?_format=json
- Posted PDFs: `https://www.fda.gov/media/{id}/download`
- Record Type **483** only (skips Untitled Letter, 483 Response, Amended 483, EIR)

Paid body fields: `id`, `firm`, `fei`, `recordDate`, `publishedOn`, `issuedOn`, `sourceUrl`, `body`, `observations[]`. `body` and `observations[].text` are official `pdftotext` extracts.

`data/form-483/` is gitignored. Observation bodies do not belong in git. The live cache lives on the media-box worker.

Free `GET /form-483/manifest.json` on `ticks.bnm.farm` is id / firm / dates only. Do not wrap that JSON as the paid payload. Family / basic-auth stay off that host.

## Env

| Variable | Default | Purpose |
|---|---|---|
| `FORM_483_DIR` | `$HOME/projects/mcp-proxy/data/form-483` | Snapshot cache (`snapshot.json` + downloaded PDFs + `skipped-no-text.json`) |
| `FORM_483_TTL_MS` | 6 hours | Unused on the request path once a real body is cached. Fill is the collect command. |
| `FORM_483_LIMIT` | `25` | Target **additional** real extractable observation bodies this run. Cached bodies are reused and do **not** count. Walks official JSON newest-first. Skips image-only / cover-only PDFs (no OCR, no invented text). `0` = keep walking |
| `FORM_483_MAX_FETCH` | `200` | Max official PDF downloads per run. Already-on-disk PDFs and persisted image-only IDs do not count. `0` = no cap |
| `FORM_483_SKIP_IDS` | unset | Comma-separated media IDs to skip (no body invented). Use to continue past the live manifest without paying for `/form-483` |
| `FORM_483_SKIP_LIVE` | unset | `1` = load media IDs from the free live manifest and skip them (id/firm/dates only) |
| `FORM_483_LIVE_MANIFEST` | `https://ticks.bnm.farm/form-483/manifest.json` | Free manifest URL when `FORM_483_SKIP_LIVE=1` |
| `FORM_483_KNOWN_MANIFEST` | unset | Local JSON path with `{ mediaIds }` or `{ letters: [{ mediaId }] }` |
| `FORM_483_HTML_DIR` | unset | Optional already-fetched `listing.json` / listing HTML + text excerpts |
| `FORM_483_PDFTOTEXT` | `pdftotext` | Poppler extractor |

Do not set `X402_SKIP_SETTLE` on the standing public unit. Family / basic-auth stay off `ticks.bnm.farm`.

## Media-box collect (required for live)

This cloud VM cannot publish `ticks.bnm.farm`. Live `letterCount` does not move until the media-box worker runs collect and restarts the door.

PR 18 still describes a live cache of **3**. PR 19 still says **189**. Live `letterCount` on `ticks.bnm.farm` is **289** (verified 2026-08-19 against the free manifest). Official OII FOIA JSON still lists **2120** unique Record Type 483 PDFs. `FORM_483_LIMIT` is **additional** extractable bodies this run — cached / live IDs do not consume it.

This Cursor cloud VM does not use the media-box worker. A VM collect does not change live `letterCount`. Deploy to `ticks.bnm.farm` only after the public manifest count actually rises.

```bash
# on the media-box / apollo host (not this cloud VM)
sudo apt-get install -y poppler-utils
cd ~/projects/mcp-proxy
git fetch origin
git checkout cursor/form-483-keep-filling-6dfc
npm run build

export FORM_483_DIR=$HOME/projects/mcp-proxy/data/form-483

# keep the 289 cached bodies, add more extractable (skip image-only)
FORM_483_LIMIT=50 FORM_483_MAX_FETCH=400 npm run collect:form-483

# later fills — LIMIT is additional, not total
FORM_483_LIMIT=80 FORM_483_MAX_FETCH=400 npm run collect:form-483

# keep walking until every extractable posted 483 is cached (slow; 2000+ PDFs)
FORM_483_LIMIT=0 FORM_483_MAX_FETCH=0 npm run collect:form-483

npm run test:ticks
systemctl --user restart idaho-ticks-x402
```

`skipped-no-text.json` remembers image-only / cover-only media IDs so the next fill does not re-download them. `snapshot.json` is never wiped when the official listing misses.

The door only serves bodies already in `FORM_483_DIR/snapshot.json`. Re-running collect fills that file. Restart the ticks door after collect so the paid payload and free manifest pick up the new count.
